# CodeLens CLI

The CLI is intentionally kept as a separate Windows executable/package boundary.

Planned commands:

- `codelens start`
- `codelens stop`
- `codelens status`
- `codelens doctor`
- `codelens providers`
- `codelens models`
- `codelens analyze`
- `codelens explain`

The CLI must share the same permission and privacy policy as the desktop application.
