# Privacy Model

CodeLens is designed around minimum necessary context.

Default principles:

- no persistent source-code storage
- no source-code telemetry
- telemetry off by default
- local-only privacy mode available
- cloud requests controlled by user policy
- secrets redacted before cloud transmission
- AI providers do not receive direct filesystem access

Provider-specific data retention is controlled by the provider and must be reviewed by the user before enabling cloud AI.
